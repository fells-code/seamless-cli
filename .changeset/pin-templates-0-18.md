New projects scaffold the starters from `seamless-templates` `v0.18.0` (was `v0.17.0`). Every starter now ships an `AGENTS.md` and a `CLAUDE.md`, so the root guide `seamless init` writes links each starter's `AGENTS.md` instead of its README, and the Go (Gin), Rust (Axum) and Python (FastAPI) api starters are available as `beta`.
